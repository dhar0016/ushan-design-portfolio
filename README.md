# Ushan Dharmawardena — Design Portfolio

**Live portfolio:** [ushan-design-portfolio](https://dhar0016.github.io/ushan-design-portfolio/)  
**Focus:** Graphic design · UI/UX · Digital content · Photography

A responsive, image-led portfolio presenting 14 collections of selected work. Each project page gives context for the visual choices, including its intended audience or customer need, colour rationale, and design approach. Where an original client brief was unavailable, the project objective is described as an interpretation of the work rather than a verified client requirement.

## Design direction

The visual system keeps the work in focus while giving the site a recognisable identity.

- **Deep navy** gives the typography and interface a steady, professional foundation.
- **Warm red** highlights important actions and adds energy without competing with the artwork.
- **White and soft neutral surfaces** create space around images and support comfortable reading.
- **Display and sans-serif typography** pair personality with clear navigation and project details.

These choices support a practical hiring-manager journey: understand Ushan’s focus, scan selected work, open a project for its design reasoning, then reach out.

## How I approach a brief

1. Clarify the audience, goal, message, format, and constraints.
2. Organize information by importance and choose a visual direction that fits the audience.
3. Build and refine the layout, typography, imagery, and colour choices.
4. Check legibility, consistency, responsiveness, and the final export or interface.
5. Share the work and incorporate useful client feedback.

For portfolio entries without a supplied brief or performance data, the notes explain the visible design decisions and avoid claiming unverified research or results.

## Explore the work

The site includes graphic design, UI/UX, promotional content, print, stationery, photography, restoration, and illustration. Browse by category or open a collection for larger artwork and project notes.

Some project entries include links to existing Figma prototypes. Prototype access depends on the sharing settings of those Figma files.

## Built with

Semantic HTML, CSS, and vanilla JavaScript. GitHub Pages serves the static site; there is no build step or package installation.

- Responsive navigation and project-category filters
- Accessible image descriptions and enlarged artwork viewing
- Reduced-motion support
- Locally bundled Manrope and DM Serif Display fonts with their SIL Open Font License files

## Run locally

Open `index.html` in a modern browser. Keep the `assets` and `projects` folders beside it. No installation is required.

## Update the portfolio

- Homepage text, About section, contact details, or project cards: `index.html`
- Project descriptions and images: the relevant HTML file in `projects/`
- Colours, typography, spacing, and responsive layout: `assets/styles.css`
- Filters, mobile navigation, and image viewer: `assets/script.js`
- New artwork: add appropriately sized files under `assets/images/`, then reference them from the project page and homepage card. Include descriptive alt text.

Keep the repository’s root `index.html` in place so GitHub Pages can publish the site.
