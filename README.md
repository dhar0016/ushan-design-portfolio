# Ushan Dharmawardena — design portfolio

A responsive portfolio of graphic design, UI/UX, digital content, and photography. Includes 14 project pages, category filters, enlarged artwork viewing, a mobile menu, and email contact links.

## Preview on your computer

Open `index.html` in Chrome, Edge, Firefox, or Safari. Keep the `assets` and `projects` folders beside it. No installation or build command is required.

## Publish to a new GitHub repository

1. Sign in to GitHub and open https://github.com/new.
2. Choose owner `dhar0016` and name the new repository `ushan-design-portfolio`.
3. Choose **Public**, enable **Add README**, and create the repository.
4. Choose **Add file → Upload files**. Upload the contents of this folder, including `index.html`, `assets`, `projects`, `README.md`, and `.nojekyll`. Upload from inside the extracted folder, so `index.html` appears at the top level of the repository.
5. Save the upload on `main` with a commit message such as `Publish design portfolio`.
6. Go to **Settings → Pages**.
7. Under **Source**, choose **Deploy from a branch**.
8. Choose branch **main**, folder **/(root)**, and click **Save**.
9. Wait for the Pages deployment to complete. It can take up to 10 minutes.
10. Use the actual **Visit site** link shown in Settings → Pages. With the owner and repository name above, the expected link is https://dhar0016.github.io/ushan-design-portfolio/.

The expected address is a publishing target, not confirmation that a repository or live website has been created.

## Add the link to your résumé

After the website works in a signed-out browser window, add a line such as:

`Portfolio: https://dhar0016.github.io/ushan-design-portfolio/`

In Word, select the URL, press Ctrl+K, and insert the same full URL. Export to PDF and test the clickable link in the PDF. Use the published website address for hiring managers; the `github.com` repository address opens the source files.

## Make changes later

- Introduction, contact information, project cards, and About text: edit `index.html`.
- A project's description and artwork: edit its HTML file inside `projects`.
- Colours, fonts, spacing, and responsive layout: edit `assets/styles.css`.
- Filters, mobile navigation, and image viewer: edit `assets/script.js`.
- New artwork: add it to `assets/images`, then add its image reference to a project page and its project card to `index.html` as needed. Use descriptive alternative text.

The site uses relative links so it can be hosted in a GitHub Pages project folder. If you choose a different repository name, the site files still work; use GitHub's final published URL on your résumé.

## Content and image notes

The artworks come from the supplied `portfolio_2024` collection. The two eagle illustrations are excluded. Additional social graphics already present in that collection are included in the new gallery. The descriptions explain the available designs; they do not claim measured results, customer research, or unsupported project outcomes.

The Greeny Organics project links to the existing Figma prototype. Its title card is a project cover, not a screenshot of the app. Park Here includes three existing interface screenshots. Test both Figma links while signed out and make the prototypes viewable by the intended audience if needed.

Large artworks have separate preview and larger WebP files, with descriptive alt text and lazy loading below the main introduction. The files preserve the proportions of the available artwork; low-resolution source images are not artificially enlarged.

Manrope and DM Serif Display are bundled with their SIL Open Font License files in `assets/fonts`.
